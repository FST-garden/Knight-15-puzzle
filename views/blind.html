盲解探索

三循环：接应 → 转环 → 撤回。执行路线使用固定位置编号1～16，不需要根据当前棋子数字选择移动。原位公式以空格16为起止位置，完整结束后只轮换三个指定位置。

怎样选择三循环

箭头表示棋子的去向，区别于下方空格执行路线。「A → B → C → A」表示A处的棋子去B、B处去C、C处去A。

  1. 挑未归位的位置B；找到应该放在B的棋子，目前在A。
  2. 找到应该放在A的棋子，目前在C。
  3. 若C≠B，执行 A → B → C → A，A与B同时归位。其他已归位位置在整段结束后恢复。
  4. 若C＝B，这是两块互换，先处理其他长度至少为3的错位循环。
  5. 只剩两两互换时，每次取两对(A,B)与(C,D)，先执行 A → B → C → A，再执行 A → D → C → A，四块归位。两段须按顺序完整执行。

例：位置2、3、4上分别是3、4、2，执行 4 → 2 → 3 → 4，三块归位。合法局面且空格在16时，棋子是偶置换；只剩两两互换时，交换对必为偶数。任意可解局面可以拆成三循环，但不能因此推断所有短公式子集都已验证覆盖。

接应、覆盖范围与当前验证

短结构为接应S → 四步转环R → 原路撤回S。撤回的是位置路线。接应k步，完整宏2k＋4步。你的研究上限是接应≤20步，完整宏≤44步；本版已有短卡仍为接应≤8步的102种，尚未扩展到20步。不要把研究上限当作已完成枚举。

独立研究数据已为全部910种有向三循环构造并回放验证路线（空格16），已知路线4～88步，不保证最短。本页回放仍只包含102种短卡，不是全部910种；遇到缺卡不能假定本页足以执行完整方案。

原位三循环起止空格为16；对称变换可能改变起点，必须看空格提示。整段结束后才保证恢复非目标位置，中途允许借动。公式净作用已做程序验证，三循环选择规则有置换依据；尚未经过真人易用性验证或外部审计。
