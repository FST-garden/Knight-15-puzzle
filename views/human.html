先看整盘怎么推进

顺序：黄环 → 绿环 → 蓝环 → 红环。每次只处理一匹：选目标 → 空格接到下一站 → 推进目标。已归位不等于已锁定；锁定块可以在公式中途暂借，段末必须恢复。

记顺序：黄环先4、13后6、11；绿环先5、12后3、14；蓝环先2、15后9、8；最后转红环。基础版按列出的先后执行。四环是解题地图，不是四张需要死背的长公式。

  1. 认目标：颜色确定目标环，色标位置确定目标格。
  2. 按基础顺序选一匹：先4，再13、6、11；逐匹完成黄环，再绿、蓝。
  3. 找下一站：确定目标棋子下一次合法马步要到哪格，不要求一步到家。
  4. 先接空格：避开目标棋子，将空格送到下一站；需要借用锁定块时，用完整定式保证恢复。
  5. 送目标：让目标棋子进入空格；未到家则继续接应和送达。
  6. 到家后锁定：本目标完成才锁定，碰巧归位的后续棋子暂不锁。
  7. 最后收尾：按基础程序完成前三环后，沿红环转到目标局面；不是任意剩余排列都能只转红环。

只保留10↔9（15步），可以看卡，不必先背

整张卡只交换端点的空格与棋子，其他块段末恢复。可倒读，以及主对角线镜像、副对角线镜像、180°旋转。路线数字是格位，不是棋子编号。

什么时候用：接应路线受已锁定位置限制，普通马步不好通过时，这张卡可以作为一条跨位置的通道。也可以直接接送端点棋子；不是每次归位都必须使用。

在哪里用：原位连接10和9；镜像或旋转连接7和3、7和8、10和14。空格必须先到其中一个端点，另一个端点是要交换的棋子；若端点含已锁定棋子，不能直接使用而破坏锁定。

怎么选方向：先认两个端点 → 将空格安排到起点 → 选择对应对称或倒读 → 完整执行15步 → 检查空格已到另一端、其他块恢复。在“具体演示”的时间线中，标有【点对点定式】的段落就是实际使用位置。
